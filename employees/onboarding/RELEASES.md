# Releases

The work ID is issued automatically after a Pass (plain code rule, no release needed).
The acceptance email waits in Replies until the HR officer releases it.
The placement letter is attached to the acceptance email. Its dates are set automatically (the
Monday after the interview, for six months); the HR officer can change them on the candidate page.
A released email is saved in data/outbox as an .eml file (with the letter inside). Nothing is sent.
