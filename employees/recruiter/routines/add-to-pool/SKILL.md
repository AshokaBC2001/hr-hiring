# add-to-pool

Starts when: the CV is scored for every area
Done by: plain code

## What it does
- Puts the CV in the pool with the status "Waiting in pool", with its best area and score.
- If no area on the list fits, the CV still goes to the pool, with the label "No matching area".
  It is read again automatically when the HR officer adds or changes an area.
- Nothing is drafted and no one is contacted. The HR officer invites candidates from the CV pool on the Add CV page.
