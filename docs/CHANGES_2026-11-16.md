### Milestone 3 — System Hardening, Efficiency, Agent Upgrades, MongoDB Direct Mode, Hosting & Supervisor Feedback (`70cb858`)
*(UI files under `web/` were intentionally left untouched in this milestone.)*

- **Logic Fixes & Code Cleanups:**
  - **Vacancy reopen fix ([hiring/vacancies.py](hiring/vacancies.py)):** Excluded auto-closed (`" - closed: no one is finishing now."`) vacancies from the permanent `done` trainee blacklist so interns whose `Training_EndDate` was extended in MongoDB properly open a vacancy once their new end date enters the 7-day notice period. Re-evaluates `filled` when `places` shrinks; validates ISO dates in `add_vacancy()`; flags duplicate emails in `set_email()`; embeds `vacancy_id` directly during `invite_from_pool()`.
  - **Unmapped interns & synonyms ([hiring/checks.py](hiring/checks.py), [hiring/tools.py](hiring/tools.py)):** Added `ALIASES` mappings (`"software engineering"` → `"Backend Development"`, `"qa"` → `"Software Quality Assurance"`, `"frontend development"` / `"full stack"` → `"Web Development"`, `"information security"` → `"Cybersecurity"`, `"ui/ux design"` → `"UI/UX Design"`), reducing live MongoDB `unknown_area` interns from `57` to `1` (`Civil Engineering`). Added PDF ligature normalization (`ﬁ`, `ﬂ`, `ﬀ`, zero-width chars), parenthesized phone regex support (`+94 (77) 123-4567`), single-char `"+"` phone rejection (`len(digits) >= 7`), and exact skill synonyms (`Excel`/`Microsoft Excel`, `CI/CD`/`CICD`, `PowerPoint`, `REST API`, `UI Design`).
  - **Race condition & dead-code removal ([hiring/flows.py](hiring/flows.py), [hiring/actions.py](hiring/actions.py)):** Replaced racy `_kick()` spawning with thread-safe `flows.kick_background()` coalescing (`_kick_lock`), reused `_profile()`, and removed unused `_draft_facts()` tuple slots.
- **Performance & SQLite Concurrency:**
  - **Scoring speedup ([hiring/tools.py](hiring/tools.py)):** Pre-tokenized `CVText` once per CV and once per project/experience item inside `score_all_areas()` and `best_area_by_rules()` instead of rebuilding `CVText` per-term across 28 areas.
  - **SQLite WAL & indexes ([hiring/db.py](hiring/db.py)):** Enabled `PRAGMA journal_mode=WAL`, `PRAGMA synchronous=NORMAL`, `PRAGMA foreign_keys=ON`, `PRAGMA busy_timeout=5000`, added indexes on `candidates(email)`, `drafts(status)`, `events(at)`, `runs(started_at)`, and added batch `get_candidates_by_app_nos()`. Added WAL files to [.gitignore](.gitignore).
  - **API & HTTP optimization ([hiring/server.py](hiring/server.py), [hiring/llm.py](hiring/llm.py), [hiring/talent_hub.py](hiring/talent_hub.py)):** Eliminated N+1 candidate queries on `/api/vacancies`, stopped loading full `cv_text` columns on `/api/state`, preloaded pool candidates per vacancy pass, added persistent pooled `httpx.Client` transports, and added a 15-second invalidated HTTP read cache for intern lists.
- **AI Agent & LLM Upgrades:**
  - **Cached & slimmer prompts ([hiring/employees.py](hiring/employees.py), [hiring/flows.py](hiring/flows.py)):** Cached Markdown prompts by `st_mtime_ns`, stripped non-LLM metadata headers, compacted `AREAS` JSON in `r_choose_area`, expanded `LESSON_RULES`, and added `HR_ALLOW_RULES_ONLY=1` deterministic fallback support.
